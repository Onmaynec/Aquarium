# Living Aquarium V3

Living Aquarium V3 — автономный браузерный аквариум на Canvas 2D. В этой версии проект уже можно запускать обычным двойным кликом: runtime не зависит от `fetch()` и локальный HTTP-сервер не обязателен.

## Что есть в V3

Сцена построена вокруг простой симуляции стаи на основе Boids. Рыбы держат дистанцию, выравнивают направление, собираются в группу, избегают границ и реагируют на корм и действия пользователя.

Отдельно работает хищник — барракуда. Она выбирает цель, пытается перехватить её с упреждением, делает рывок и после атаки уходит на короткое восстановление.

В аквариуме также есть:

- шесть видов обычных рыб;
- кормление с временным изменением поведения стаи;
- ночной режим;
- растения, кораллы, камни, ракушки, улитки и креветки;
- пузырьки, световые лучи и движущаяся каустика;
- фоновые звуки воды и эффекты кормления;
- сохранение пользовательских настроек в `localStorage`;
- управление мышью и касанием;
- пауза и полноэкранный режим.

## Управление

| Действие | Что происходит |
| --- | --- |
| Клик или касание воды | стая на короткое время разбегается от точки |
| `Покормить` | в воду падают хлопья, рыбы начинают искать корм |
| `Добавить` | добавляется случайная рыба |
| `Ночь` | переключается ночной режим |
| `Звук` | включаются или выключаются звуки |
| `⚙️` | открываются настройки поведения и эффектов |

## Запуск

Самый простой вариант — открыть `index.html` или запустить `START-AQUARIUM.bat` на Windows.

HTTP-сервер нужен только если хочется проверить проект в условиях обычной веб-раздачи:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080/`.

## Как устроен проект

- `index.html` — разметка приложения;
- `styles.css` — интерфейс и адаптивные стили;
- `app.js` — симуляция, управление и отрисовка;
- `assets/manifest.js` — данные подготовленных графических и звуковых ресурсов;
- `assets/` — рыбы, окружение, растения и декоративные элементы;
- `docs/ASSETS.md` — описание обработки исходных материалов;
- `docs/asset-map.json` — соответствие исходных UUID-имён новым файлам.

Проект не использует runtime-фреймворки или внешние JavaScript-библиотеки.

## Ассеты

Исходный набор состоял из 40 файлов с техническими UUID-именами. Материалы были разобраны по назначению, переименованы и подготовлены для браузера. Крупные sprite sheets разрезаны на используемые элементы, пустые прозрачные поля убраны, а растровая графика собрана в компактные WebP-атласы внутри SVG-контейнеров.

Подробности находятся в [`docs/ASSETS.md`](docs/ASSETS.md), полная карта переименований — в [`docs/asset-map.json`](docs/asset-map.json).

## Производительность

Отрисовка рассчитана на плавную работу в браузере: статические данные не пересортировываются каждый кадр, размер внутренних изображений ограничен реальной задачей, а тяжёлые Canvas-фильтры не используются без необходимости.

## Материалы и лицензирование

Графика и звуки были предоставлены владельцем репозитория. В исходном архиве отдельного файла лицензии не было, поэтому перед сторонним или коммерческим распространением материалов их лицензионный статус нужно проверить отдельно.
