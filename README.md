# Living Aquarium — V10 Ocean Command Center branch

V10 — текущая верхняя точка этой ветки: V6 Ocean Lab остаётся базовым симулятором, а V7, V8, V9 и V10 подключаются поверх него отдельными модулями с независимыми сохранениями.

## Точки входа

- `index.html` — V6;
- `v7.html` — Deep Sea Expedition;
- `v8.html` — Marine Genetics Lab;
- `v9.html` — Reef Restoration Center;
- `v10.html` — полный стек с Ocean Command Center.

Для проверки V10 из исходников используйте `v10.html`.

## Ocean Command Center

Командный центр открывается клавишей `C` и хранит состояние в:

```text
aquarium-v10-command
```

В распоряжении три судна — Nautilus, Calypso и Nereid. Каждое может выполнять одну миссию, поэтому одновременно возможно до трёх операций.

## Регионы

| Регион | Риск | Влияние для открытия |
| --- | ---: | ---: |
| Прибрежный контур | 4% | 0 |
| Коралловый пояс | 8% | 90 |
| Пелагический маршрут | 12% | 220 |
| Полярное течение | 17% | 430 |
| Абиссальная сеть | 23% | 760 |

Итоговый шанс миссии также зависит от базового шанса операции, уровня навигатора, исследовательского уровня и в отдельных случаях генетика.

## Операции

Доступны пять заданий реального времени: биосферная перепись, генетический резерв, коралловый мост, перехват загрязнения и абиссальный ретранслятор. Они расходуют кредиты, разведданные и/или снабжение и отличаются длительностью, риском и наградой.

Успешные операции дают XP, влияние, разведданные и повышают Ocean Index. Неудача сбрасывает серию успешных миссий и снижает индекс.

## Команда

Пять специалистов развиваются до 5 уровня:

- навигатор повышает шанс успеха;
- генетик усиливает генетические операции;
- эколог увеличивает прирост Ocean Index;
- инженер сокращает время миссий;
- аналитик увеличивает награду разведданными.

## Ocean Index

Индекс ограничен диапазоном 0–100. Помимо обычных операций доступна стабилизационная программа за 240 кредитов, 18 разведданных и 8 единиц снабжения. Она повышает Ocean Index, влияние и XP.

## Наследие V7–V9

V10 один раз читает погружения и образцы V7, генетический прогресс V8 и результаты восстановления V9. На их основе начисляются стартовые кредиты, разведданные, снабжение, влияние, XP и небольшой бонус Ocean Index. Старые сохранения не изменяются.

## Достижения

В V10 шесть достижений: первая завершённая операция, три одновременные миссии, Ocean Index 75+, открытие всех регионов, серия из семи успехов и 100 завершённых операций.

## Запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/v10.html`.

## Сборка и проверка

```bash
node --check bootstrap-v10.js
node --check v10-command.js
node --check service-worker-v10.js
node tests/command-center-test.js
node tests/v10-runtime-test.js
python3 scripts/build-v10-release.py dist/v10-stage
```

Release builder объединяет V6–V10 в автономную PWA-сборку с обычным `index.html`.
