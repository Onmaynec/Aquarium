# Aquarium — ранняя рабочая ветка

`agent/interactive-aquarium` — историческая ветка проекта, созданная до появления оформленных версий Living Aquarium.

В ней нет актуальной V3–V10 документации и нет смысла использовать её как точку входа для текущего приложения. Ветка сохранена как раннее состояние разработки и нужна только если требуется посмотреть историю проекта до последующих релизных веток.

Для актуальной версии используйте `main`. Для изучения конкретных этапов развития проекта лучше открывать соответствующие ветки `agent/aquarium-v*-...`, где README описывает код именно этой версии.

Эту ветку не следует использовать как источник инструкций по сборке или запуску современных релизов Aquarium.
