# Living Aquarium V6 Ocean Lab

Living Aquarium V6 развивает V5 в сторону научной песочницы. Базовая экосистема остаётся прежней, но поверх неё появляются биомы, телеметрия, исследовательские миссии и автоматический смотритель.

Версия ветки — **6.0.0**.

## Ocean Lab

Лаборатория открывается кнопкой интерфейса или клавишей `L`. В ней собраны история состояния воды и популяции, исследовательский XP, миссии, журнал автоматизации и переключение биома.

Доступны три среды:

- **Коралловый риф** — сбалансированные параметры воды;
- **Лес ламинарии** — более прохладная вода, высокий кислород и сильное течение;
- **Лунная лагуна** — тёплая спокойная среда, удобная для развития поколений.

Выбранный биом меняет целевые параметры воды, течение и визуальное состояние сцены.

## Умный смотритель

Автопилот можно включить по желанию. Он следит за водой и состоянием рыб и при необходимости управляет фильтром, аэратором и нагревателем, делает аварийную подмену воды, кормит стаю и запускает лечение.

Все действия смотрителя попадают в журнал, поэтому автоматизация остаётся наблюдаемой, а не работает полностью скрыто.

## Исследования

Шесть миссий связаны со стабильностью воды, биоразнообразием, редкими поколениями и оформлением среды. За выполнение начисляется XP и повышается исследовательский ранг.

## Что осталось от V5

V6 сохраняет размножение и икру, генетику и редкости, заболевания, случайные события, энциклопедию, редактор дна, достижения, дзен-режим, фоторежим и три слота сохранения.

## Сохранения и импорт

При первом открытии каждый слот V5 переносится в соответствующий слот V6. Импорт принимает сохранения V4, V5 и V6.

## Управление

| Клавиша | Действие |
| --- | --- |
| `L` | открыть Ocean Lab |
| `Space` | пауза |
| `F` | корм |
| `A` | добавить рыбу |
| `E` | редактор декораций |
| `P` | фоторежим |
| `M` | звук |
| `S` | центр управления |
| `Esc` | закрыть активное окно |

## Запуск

Portable-версия работает без backend: откройте `index.html` или `START-AQUARIUM.bat` на Windows.

Для Service Worker и установки PWA нужен HTTP-контекст:

```bash
python -m http.server 8080
```

## Как хранится runtime

Основное приложение упаковано в chunks внутри `runtime/`. `bootstrap.js` распаковывает его в браузере и запускает без дополнительных runtime-запросов.

Поэтому `app.js` и внутренние smoke/integrity/Ocean Lab tests присутствуют внутри payload, а не как обычные корневые файлы этой ветки.

## Проверка исходной ветки

Команды, которые запускает CI:

```bash
node --check bootstrap.js
node --check service-worker.js
node --check assets/manifest.js
node tests/payload-test.js
```

`payload-test.js` проверяет содержимое упакованного приложения, включая внутренние тесты.
