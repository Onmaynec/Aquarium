## 🆕 Главное в V6

### 🌍 Три биома

- **Коралловый риф** — сбалансированная среда с температурой 25°C и pH 7.2.
- **Лес ламинарии** — прохладная вода, усиленное насыщение кислородом и более сильное течение.
- **Лунная лагуна** — тёплая спокойная вода для интенсивного развития поколений.

Биом меняет оттенок сцены, целевую температуру, pH, течение и динамику параметров воды.

### 🧪 Ocean Lab

Новая лаборатория открывается кнопкой **«Лаборатория»** или клавишей `L`. Она показывает:

- историю чистоты, кислорода и популяции;
- текущий исследовательский уровень и XP;
- прогресс шести научных миссий;
- журнал действий умного смотрителя;
- выбор активного биома.

### 🤖 Умный смотритель

Опциональный автопилот следит за качеством воды и состоянием стаи. Он может включить фильтр, аэратор и нагреватель, выполнить аварийную подмену воды, накормить голодных рыб и начать лечение при вспышке заболеваний.

### 🎯 Исследования

Миссии по стабильности воды, биоразнообразию, разведению редких поколений и оформлению среды дают XP. Исследовательский ранг и прогресс сохраняются вместе с аквариумом.

## ✨ Возможности экосистемы

V6 сохраняет все возможности V5: Boids, хищника, размножение и икру, генетику и редкости, болезни, случайные события, редактор дна, энциклопедию, достижения, дзен-режим, фото и три слота сохранения.

## 💾 Совместимость

Каждый слот V5 автоматически переносится в соответствующий слот V6 при первом открытии. Импорт поддерживает JSON-сохранения V4, V5 и V6.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `L` | Ocean Lab |
| `Space` | Пауза |
| `F` | Корм |
| `A` | Добавить рыбку |
| `E` | Редактор декораций |
| `P` | Фоторежим |
| `M` | Звук |
| `S` | Центр управления |
| `Esc` | Закрыть активный режим |

## 🚀 Запуск

На Windows распакуйте архив и откройте `START-AQUARIUM.bat`. Также можно открыть `index.html` напрямую — интернет и сервер не требуются.

Для PWA и Service Worker:

```bash
python -m http.server 8080
```
