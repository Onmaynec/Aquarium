# 🌊 Living Aquarium

### Интерактивный аквариум с настоящими графическими ассетами и реалистичным Boids

</div>

## ✨ Возможности

🐠 **Шесть красивых видов рыб** — рыба-клоун, скалярия, тропическая рыба, рыба-бабочка, золотая рыбка и голубой хирург.

🧠 **Boids по принципам Craig Reynolds** — разделение, выравнивание, сплочение, плавная инерция, избегание границ и естественное блуждание.

🦈 **Умная барракуда** — выбирает цель, рассчитывает упреждение, совершает рывок, отдыхает после атаки и не зацикливается на одной рыбке.

🪸 **Живое морское дно** — кораллы, ракушки, камни, улитки, креветки и десять видов растений.

🌿 **Колыхание растений** — каждая водоросль имеет собственную фазу шума, глубину и наклон.

💧 **Объёмные пузырьки** — три графических варианта с разным размером, прозрачностью и траекторией.

🌊 **Динамический свет** — подводный фон, мягкие лучи и движущаяся каустика.

🍽️ **Кормление** — хлопья падают с поверхности, а рыбы временно меняют поведение и плывут к ближайшей еде.

🎵 **Настоящие звуки** — фоновая вода, падение корма и мягкие пузырьки.

💾 **LocalStorage** — сохраняются настройки, ночной режим, количество и состав рыб.

📱 **Адаптивный интерфейс** — управление работает мышью, пальцем, на телефонах, планшетах и desktop.

## 🎮 Управление

| Действие | Результат |
|---|---|
| Клик или касание воды | Рыбы разбегаются от точки на 2 секунды |
| `Покормить` | Добавляет хлопья и привлекает стаю |
| `Добавить` | Создаёт случайный вид рыбы |
| `Ночь` | Затемняет воду и замедляет экосистему |
| `Звук` | Включает или выключает звуки воды |
| `⚙️` | Открывает настройки Boids и эффектов |

## 🚀 Запуск

Проект использует `fetch()` для загрузки манифеста, поэтому его нужно запускать через HTTP-сервер, а не двойным кликом по `index.html`.

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## ⚙️ Технологии

- Vanilla HTML, CSS и JavaScript
- Canvas 2D
- WebP-атласы, встроенные в SVG-контейнеры
- SVG-растения
- OGG/Opus audio, встроенное в манифест
- LocalStorage
- GitHub Actions и GitHub Pages

Проект не использует фреймворки и внешние библиотеки во время выполнения.

## 🧰 Обработка материалов

Все **40 файлов** из предоставленного архива были изучены и переименованы. Большие sprite sheet были разобраны на рабочие модели, прозрачные поля удалены, а графика оптимизирована для браузера. Полная схема переименования находится в [`docs/asset-map.json`](docs/asset-map.json), подробности — в [`docs/ASSETS.md`](docs/ASSETS.md).

## 📊 Производительность

Сцена оптимизирована под 60 FPS: вместо десятков отдельных больших PNG используются компактные атласы, ограничивается pixel ratio, статические коллекции не сортируются каждый кадр, а дорогостоящие Canvas-фильтры исключены.
