## 🆕 Главное в V7

### 🛥️ Глубоководные экспедиции

Новый центр экспедиций открывается кнопкой **«Экспедиция»** или клавишей `X`. Выбирайте район, следите за энергией и прочностью корпуса, запускайте батискаф и возвращайте научный груз.

Доступны четыре зоны:

- **Сумеречный риф** — безопасное первое погружение;
- **Каньон сирен** — сильные течения и кристальные образцы;
- **Абиссальная равнина** — высокое давление и редкие находки;
- **Термальные источники** — экстремальная глубина и уникальные минералы.

Новые районы открываются с ростом исследовательского уровня Ocean Lab.

### 📡 Сонар и риск

Во время погружения можно тратить энергию на сонарные импульсы. Точная разведка повышает количество образцов и снижает повреждение корпуса. После тяжёлых экспедиций батискаф необходимо заряжать и ремонтировать с помощью комплектов снабжения.

### 🧫 Научная коллекция

Экспедиции возвращают четыре типа образцов и открывают каталог глубоководных существ: фонареглаза, стеклянного кальмара, рыбу-гадюку и термального краба. Каждая миссия приносит XP Ocean Lab и продвигает исследования.

### 🏆 Новые достижения

V7 добавляет награды за первое погружение, исследование всех районов, коллекцию образцов, активное использование сонара и рискованное возвращение из бездны.

## ✨ Возможности экосистемы

V7 сохраняет всё из V6: три биома, телеметрию, научные миссии, умного смотрителя, Boids, хищника, размножение, генетику, болезни, события, энциклопедию, редактор дна, фото, дзен-режим и три слота.

## 💾 Совместимость

Все слоты V6 автоматически переносятся в V7. Импорт поддерживает сохранения V4, V5, V6 и V7.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `X` | Deep Sea Expedition |
| `L` | Ocean Lab |
| `Space` | Пауза |
| `F` | Корм |
| `A` | Добавить рыбку |
| `E` | Редактор декораций |
| `P` | Фоторежим |
| `M` | Звук |
| `S` | Центр управления |
| `Esc` | Закрыть активный режим |

## 🚀 Запуск

На Windows распакуйте архив и откройте `START-AQUARIUM.bat`. Также можно открыть `index.html` напрямую — интернет и сервер не нужны.

Для PWA и Service Worker:

```bash
python -m http.server 8080
```
