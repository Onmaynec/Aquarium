## ✨ V5 Evolution

- 🐠 Boids-поведение, индивидуальные имена и характеры рыб.
- 🦈 Хищник с отдельной логикой охоты.
- 🌿 Редактор растений и декораций.
- 🧪 Показатели чистоты, кислорода, температуры и pH.
- 🌗 Автоматический цикл дня и ночи.
- 📸 Фото-режим, достижения, сохранение и импорт мира.
- 📱 Адаптивный интерфейс и PWA.
- 💾 Запуск через GitHub Pages или локально двойным кликом по `index.html`.

## 🚀 Запуск

Откройте `index.html` в актуальном Chrome, Edge или Firefox. Для разработки можно использовать любой статический сервер:

```bash
python -m http.server 8080
```
