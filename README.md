# Living Aquarium — V7 Deep Sea overlay

Эта ветка хранит V7 как отдельный модуль поверх стабильного Living Aquarium V6. Базовая V6 не переписана: глубоководная система подключается после запуска основного симулятора и хранит свой прогресс отдельно.

## Точки входа

В исходном репозитории:

- `index.html` — базовый V6 Ocean Lab;
- `v7.html` — V6 с подключённым Deep Sea Expedition;
- `v7-expedition.js` — логика нового overlay;
- `bootstrap-v7.js` — загрузка базового runtime и подключение V7.

Для текущей версии этой ветки используйте `v7.html`.

## Deep Sea Expedition

Панель открывается клавишей `X`. В ней четыре района: Сумеречный риф, Каньон сирен, Абиссальная равнина и Термальные источники.

У батискафа есть энергия, прочность корпуса и научные комплекты. Сонар можно включать и выключать; при активном сонаре риск аварии снижается, но погружение расходует немного больше энергии.

Каждый район содержит по три возможных находки — всего **12 типов образцов**. Экспедиции дают XP, открывают новые зоны и заполняют отдельный бортовой журнал. В модуле пять достижений.

## Сохранения

V7 использует отдельный ключ:

```text
aquarium-v7-deep-sea
```

Сохранения V6 не изменяются. Overlay читает базовый симулятор как основу интерфейса, но экспедиционный прогресс хранит отдельно.

## Запуск из исходников

```bash
python -m http.server 8080
```

После запуска откройте `http://localhost:8080/v7.html`.

## Portable-релиз

Release workflow распаковывает проверенный V6 runtime, добавляет `v7-expedition.js`, заменяет manifest/Service Worker на V7-варианты и формирует обычный `index.html`. Поэтому в готовом portable-архиве отдельный `v7.html` не нужен как основная точка входа.

## Проверка

```bash
node --check v7-expedition.js
node --check bootstrap-v7.js
node tests/deep-sea-overlay-test.js
node tests/v7-runtime-test.js
```

`v7-runtime-test.js` дополнительно проверяет, что базовый V6 runtime совместим с overlay.
