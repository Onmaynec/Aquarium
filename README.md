# Living Aquarium V5 Evolution

Living Aquarium V5 — автономный браузерный симулятор аквариума, в котором первоначальная Boids-сцена уже превращена в небольшую экосистему с состоянием воды, размножением, генетикой, болезнями, событиями и сохранениями.

Версия ветки — **5.0.0**.

## Основные системы

### Рыбы и поведение

Рыбы двигаются стаей, реагируют на корм и окружение, имеют индивидуальные имена и характеристики. Отдельная логика управляет хищником.

V5 добавляет развитие популяции: икру, инкубацию, мальков и поколения. Окраска наследуется, а генетические варианты распределены по уровням редкости.

### Состояние аквариума

У воды есть чистота, кислород, температура и pH. Их приходится поддерживать обслуживанием аквариума. На экосистему также влияют течение, день/ночь, заболевания и случайные события.

### Оформление и режимы

В проекте есть редактор дна и декораций, энциклопедия открытых видов, достижения, фоторежим с экспортом PNG и дзен-режим с автоматической камерой.

### Сохранения

Доступны три независимых слота. При первом запуске V5 умеет перенести существующее сохранение V4 в первый слот.

## Запуск

Обычную автономную версию можно открыть через `index.html`. На Windows также используется `START-AQUARIUM.bat`.

Для PWA, Service Worker и проверки проекта через HTTP запустите статический сервер:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080/`.

## Как устроена сборка

В репозитории базовое приложение хранится в сжатом runtime payload. `bootstrap.js` собирает части из `runtime/`, распаковывает HTML/CSS/JavaScript в памяти и запускает приложение без дополнительных сетевых запросов.

Это позволяет одной сборке работать и с обычного статического хостинга, и локально через `file://`.

## Проверка

Корневые файлы V5 можно проверить так:

```bash
node --check bootstrap.js
node --check service-worker.js
node tests/payload-test.js
```

`payload-test.js` распаковывает runtime и отдельно убеждается, что внутри присутствуют `app.js`, `index.html`, `styles.css` и базовые smoke/integrity tests.

- `Aquarium-V5.0.0-SHA256SUMS.txt` — контрольные суммы архивов.

История изменений находится в [`CHANGELOG.md`](CHANGELOG.md), подробности релиза — в [`RELEASE_NOTES.md`](RELEASE_NOTES.md).

## Технологии

Проект использует Vanilla HTML/CSS/JavaScript, Canvas 2D, `localStorage`, Service Worker, PWA manifest и GitHub Actions. Отдельный backend для симуляции не требуется.
