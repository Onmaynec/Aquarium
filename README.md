# Living Aquarium V7 Deep Sea Expedition

Living Aquarium V7 расширяет Ocean Lab полноценными глубоководными экспедициями. В этой ветке Deep Sea Expedition встроен в основную линию релиза: прогресс исследований открывает новые районы, а результаты погружений сохраняются вместе с состоянием V7.

Версия ветки — **7.0.0**.

## Deep Sea Expedition

Центр экспедиций открывается кнопкой интерфейса или клавишей `X`.

Доступны четыре района:

- **Сумеречный риф** — стартовая зона с относительно низким риском;
- **Каньон сирен** — более сильные течения и ценные образцы;
- **Абиссальная равнина** — высокое давление и редкие находки;
- **Термальные источники** — глубокая зона с экстремальными условиями.

Новые маршруты открываются по мере роста исследовательского прогресса Ocean Lab.

## Батискаф и сонар

У батискафа есть запас энергии, прочность корпуса и комплекты снабжения. Во время погружения можно использовать сонар: он расходует энергию, но повышает качество разведки и снижает вероятность серьёзного повреждения.

После тяжёлых миссий аппарат приходится обслуживать и пополнять запасы.

## Научные данные

Погружения возвращают образцы, открывают записи о глубоководных существах и дают XP Ocean Lab. Отдельные достижения связаны с первым погружением, исследованием районов, использованием сонара и сбором коллекции.

## Что осталось от V6

V7 сохраняет три биома, телеметрию, научные миссии, умного смотрителя, размножение и генетику, заболевания, события, энциклопедию, редактор декораций, фоторежим, дзен-режим и PWA.

## Сохранения

Слоты V6 мигрируют в V7. Импорт поддерживает JSON-сохранения V4–V7.

## Управление

| Клавиша | Действие |
| --- | --- |
| `X` | открыть Deep Sea Expedition |
| `L` | открыть Ocean Lab |
| `Space` | пауза |
| `F` | корм |
| `A` | добавить рыбу |
| `E` | редактор декораций |
| `P` | фоторежим |
| `M` | звук |
| `S` | центр управления |
| `Esc` | закрыть активное окно |

## Запуск

Portable-сборка работает автономно через `index.html` или `START-AQUARIUM.bat`.

Для Service Worker и PWA используйте HTTP:

```bash
python -m http.server 8080
```

## Runtime и проверка

Основное приложение этой ветки хранится внутри runtime payload. Корневой CI проверяет упаковщик и содержимое payload следующими командами:

```bash
node --check bootstrap.js
node --check service-worker.js
node --check assets/manifest.js
node tests/payload-test.js
```

Внутри payload находятся базовые smoke/integrity/Ocean Lab проверки и тест Deep Sea Expedition.
