# Living Aquarium

Living Aquarium — автономный браузерный симулятор аквариума. Проект работает без игрового сервера: состояние хранится локально, а основные механики реализованы на HTML, CSS и JavaScript.

Актуальная версия — **V9.0.0, Reef Restoration Center**. Она работает поверх базового аквариума V6 и дополнений V7/V8, не перезаписывая их сохранения.

## Что есть в проекте

Базовый аквариум включает симуляцию стаи, параметры воды, кормление и размножение рыб, болезни, события, декорации, достижения, фоторежим и локальные сохранения.

Поверх него постепенно добавлялись отдельные системы:

- **V6 Ocean Lab** — биомы, телеметрия, научные миссии и автоматический смотритель;
- **V7 Deep Sea Expedition** — глубоководные экспедиции и сбор образцов;
- **V8 Marine Genetics Lab** — лаборатория генетики и работа с фенотипами;
- **V9 Reef Restoration Center** — восстановление рифов, коралловый питомник, экологические проекты и климатические события.

Подробности текущего релиза находятся в [`README-V9.md`](README-V9.md). История V9 вынесена в [`CHANGELOG-V9.md`](CHANGELOG-V9.md), а текст релиза — в [`RELEASE_NOTES-V9.md`](RELEASE_NOTES-V9.md).

## Reef Restoration Center

Центр восстановления открывается клавишей `R`. В нём четыре сектора:

- Лагуна рассвета;
- Коралловый сад;
- Внешний шельф;
- Голубая впадина.

У каждого сектора есть здоровье рифа, загрязнение и тепловой стресс. Репутация открывает новые зоны, а кредиты, дроны и выращенные колонии расходуются на обследование, очистку, охлаждение и высадку кораллов.

Питомник рассчитан на шесть ячеек и поддерживает четыре культуры: ветвистую акропору, морской веер, мозговой коралл и ламинариевый купол.

V9 хранит прогресс отдельно в `aquarium-v9-restoration`. При первом использовании он может начислить одноразовый бонус за прогресс Deep Sea Expedition и Marine Genetics Lab. Сохранения V7 и V8 при этом не изменяются.

## Как запустить

### Готовый релиз

В portable-архиве V9 точкой входа является `index.html`. На Windows также можно использовать `START-AQUARIUM.bat`.

Для PWA-функций лучше запускать каталог через локальный HTTP-сервер:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080/`.

### Из исходников репозитория

В корне репозитория сохранены точки входа предыдущих версий. Для V9 используйте `v9.html`:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080/v9.html`.

Корневой `index.html` относится к базовой V6 и оставлен для совместимости.

## Сборка V9

Сборщик распаковывает базовый runtime, добавляет V7, V8 и V9, а затем формирует каталог релиза с актуальными manifest, Service Worker, тестами и документацией.

```bash
python3 scripts/build-v9-release.py dist/v9-stage
```

В собранном каталоге V9 становится обычным `index.html`.

## Проверка

Основные проверки текущего релиза:

```bash
node --check bootstrap-v9.js
node --check v9-restoration.js
node --check service-worker-v9.js
node tests/deep-sea-overlay-test.js
node tests/genetics-lab-test.js
node tests/restoration-center-test.js
node tests/v9-runtime-test.js
python3 scripts/build-v9-release.py dist/v9-stage
```

CI дополнительно запускает базовые smoke-, integrity- и Ocean Lab-тесты уже на собранной V9.

## Структура V9

- `v9.html` — точка входа V9 в исходном репозитории;
- `bootstrap-v9.js` — распаковка базового runtime и подключение V7–V9;
- `v9-restoration.js` — логика Reef Restoration Center;
- `manifest-v9.webmanifest` и `service-worker-v9.js` — PWA-конфигурация;
- `scripts/build-v9-release.py` — воспроизводимая сборка релиза;
- `tests/` — проверки базового аквариума и последующих дополнений.

Проект не требует отдельного backend для игрового процесса: основная симуляция и сохранения работают в браузере.
