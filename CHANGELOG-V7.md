# Changelog — Living Aquarium V7

## 7.0.0 — Deep Sea Expedition

### Added

- Отдельная точка входа `v7.html` поверх стабильного ядра V6.
- Четыре глубоководных района с разной глубиной, стоимостью энергии и риском.
- Батискаф: энергия, прочность корпуса, научные комплекты и обслуживание.
- Активный сонар, снижающий вероятность аварии.
- 12 типов научных образцов и каталог находок.
- XP Ocean Lab, бортовой журнал и статистика погружений.
- Пять достижений Deep Sea Expedition.
- Горячая клавиша `X` и адаптивная панель экспедиции.
- Независимое сохранение `aquarium-v7-deep-sea`.

### Infrastructure

- Интеграционный тест V7 повторно проверяет runtime V6 и новый overlay.
- Отдельные CI, tag и release workflows для линии V7.
- Release workflow создаёт Portable ZIP, Source ZIP и SHA256SUMS.
