# Changelog — Living Aquarium V9

## 9.0.0 — Reef Restoration Center

### Added

- отдельный Reef Restoration Center overlay с клавишей `R`;
- четыре сектора с независимыми показателями здоровья, загрязнения и теплового стресса;
- открытие новых зон через экологическую репутацию;
- питомник на шесть ячеек и четыре коралловые культуры;
- обследование, очистка дронами, охлаждение и высадка колоний;
- кредиты, фрагменты, колонии, дроны, репутация и XP;
- случайные климатические события;
- пять достижений и журнал восстановления;
- одноразовый бонус по данным V7/V8;
- отдельное сохранение `aquarium-v9-restoration`;
- `v9.html`, V9 manifest, Service Worker и воспроизводимый release builder.

### Compatibility

- базовый V6 runtime и overlays V7/V8 не переписываются;
- V9 читает предыдущий прогресс только для расчёта бонуса;
- весь прогресс Reef Restoration Center хранится отдельно;
- release builder объединяет V6–V9 в автономный `index.html`.
