# Changelog

## 10.0.0 — Ocean Command Center

### Added
- единый Ocean Command Center с клавишей `C`;
- глобальный Ocean Index от 0 до 100;
- исследовательский флот из трёх судов;
- пять регионов с разным риском и бонусами;
- пять операций реального времени;
- пять специалистов с пятью уровнями развития;
- ресурсы командного центра: кредиты, разведданные, снабжение, влияние и XP;
- глобальная стабилизационная программа;
- шесть достижений и оперативный журнал;
- безопасная одноразовая синхронизация прогресса V7, V8 и V9;
- отдельное сохранение `aquarium-v10-command`;
- V10 entrypoint, PWA-конфигурация, offline cache, тесты, release-builder и GitHub Actions.

### Changed
- release-сборка теперь включает overlays V7–V10;
- service worker удаляет только старые кэши Living Aquarium и не затрагивает сторонние кэши origin;
- навигационные запросы используют network-first с offline fallback.

### Compatibility
- ядро V6 и overlays V7–V9 не изменены;
- V10 читает предыдущие сохранения только для расчёта наследия;
- прогресс командного центра полностью изолирован.
