# 🌊 Living Aquarium V5 Evolution — 5.0.0

V5 превращает демонстрацию Boids в автономный симулятор живой экосистемы. Сборка запускается двойным кликом, не требует сервера и сохраняет прогресс в браузере.

## Главное

- 🐣 размножение, икра, инкубация и рост мальков;
- 🧬 наследуемая окраска, поколения и четыре уровня редкости;
- 🦠 болезни, диагностика и лечение;
- ⚡ случайные события экосистемы;
- 🌊 настраиваемое течение воды;
- 📖 энциклопедия открытых видов и генетических вариантов;
- 💾 три независимых слота сохранения;
- 🧘 дзен-режим с автоматической камерой;
- 🪸 редактор дна и декораций;
- 📸 фоторежим с экспортом PNG;
- 📲 полноценный PWA-манифест, иконки 192/512 и офлайн-кэш;
- 🚀 автоматическое тестирование, GitHub Pages и публикация архивов по тегу.

## Исправления и стабилизация

- удалены дублирующиеся функции, оставшиеся после расширения V4;
- сохранён автономный запуск через `file://` без `fetch()`;
- добавлены резервные процедурные модели при ошибке декодирования ассета;
- исправлена стратегия Service Worker: HTML используется как fallback только для навигации;
- добавлена автоматическая проверка DOM-ссылок, встроенных ассетов и PWA-файлов;
- сохранена миграция аквариума из V4 в первый слот V5.

## Запуск

На Windows распакуйте архив и откройте `START-AQUARIUM.bat`. Также можно открыть `index.html` напрямую.

Для PWA и Service Worker используйте GitHub Pages или локальный сервер:

```bash
python -m http.server 8080
```

## Проверка

```bash
node --check app.js
node --check assets/manifest.js
node --check service-worker.js
node tests/smoke-test.js
node tests/integrity-test.js
```
