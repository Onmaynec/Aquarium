# Living Aquarium V6 Ocean Lab — 6.0.0

V6 — базовая линия для последующих overlay-модулей. Она добавляет три биома, телеметрию, исследовательские миссии и умного смотрителя.

Слоты V5 переносятся в V6, импорт поддерживает V4–V6. Основной runtime упакован и проверяется через `bootstrap.js` и `tests/payload-test.js`.

Release notes V7–V10 находятся в отдельных файлах рядом с документацией соответствующего overlay.
