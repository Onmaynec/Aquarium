# Living Aquarium V5 Evolution — 5.0.0

V5 — первый релиз Aquarium, где проект работает не только как демонстрация поведения стаи, а как автономная экосистема с долгоживущим состоянием.

## Что изменилось

Рыбы теперь размножаются, проходят стадии икры и малька, наследуют окраску и формируют поколения. Генетические варианты разделены по редкости, а открытые виды и варианты попадают в энциклопедию.

Состояние аквариума зависит от чистоты воды, кислорода, температуры и pH. Появились болезни, лечение, течение и случайные события, поэтому сохранённый мир со временем меняется, а не остаётся статичной сценой.

Для оформления добавлены редактор дна и декораций, фоторежим с PNG-экспортом и дзен-режим. Прогресс хранится в трёх слотах; старое сохранение V4 может быть перенесено в первый слот V5.

## Автономный запуск

Portable-сборка не требует backend и может открываться через `index.html` или `START-AQUARIUM.bat`. Для Service Worker и установки PWA нужен обычный HTTP-контекст, например:

```bash
python -m http.server 8080
```

## Проверка исходной ветки

В репозитории приложение находится внутри сжатого runtime payload, поэтому корректные корневые проверки выглядят так:

```bash
node --check bootstrap.js
node --check service-worker.js
node tests/payload-test.js
```

`payload-test.js` распаковывает payload и проверяет наличие внутреннего `app.js`, HTML/CSS и базовых тестов.

## Артефакты релиза

GitHub Release содержит portable-архив, source-архив и файл SHA-256 контрольных сумм. Release workflow собирает их только после проверки runtime payload.
