## 🆕 Главное в V8

### 🧬 Marine Genetics Lab

Откройте лабораторию кнопкой **«Генетика»** или клавишей `G`. Секвенируйте родительские линии, собирайте ДНК, скрещивайте геномы и выращивайте гибридов в инкубаторе.

Исследуются пять локусов:

- окраска;
- форма плавников;
- размер;
- биолюминесценция;
- устойчивость организма.

### 🐠 Родительские линии

Доступны шесть линий: коралловая, жемчужная, абиссальная, термальная, лунная и призматическая. Продвинутые линии открываются через лабораторный XP и результаты глубоководных экспедиций V7.

### 🧫 Селекция и мутации

Скрещивание создаёт эмбрион с наследуемыми аллелями обоих родителей. Возможны контролируемые мутации. Геном можно стабилизировать перед выращиванием, чтобы повысить исследовательскую ценность гибрида.

### ✨ Фенотипический атлас

Открывайте восемь редких фенотипов: биолюминесцентный, призматический, вуалехвостый, гигантский, иммунный страж, лунный жемчуг, термостойкий и дикий гибрид.

### 🌊 Связь с V7

Научные образцы Deep Sea Expedition можно один раз преобразовать в ДНК и XP. Состояние V7 не изменяется: V8 использует отдельный ключ `aquarium-v8-genetics`.

## ✨ Наследие предыдущих версий

V8 сохраняет V7 Deep Sea Expedition и всё ядро V6 Ocean Lab: три биома, телеметрию, миссии, умного смотрителя, Boids, размножение, болезни, события, редактор дна, фото, дзен-режим и три слота сохранений.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `G` | Marine Genetics Lab |
| `X` | Deep Sea Expedition |
| `L` | Ocean Lab |
| `Space` | Пауза |
| `F` | Корм |
| `A` | Добавить рыбку |
| `E` | Редактор декораций |
| `P` | Фоторежим |
| `M` | Звук |
| `S` | Центр управления |
| `Esc` | Закрыть активный режим |

## 🚀 Запуск

На Windows распакуйте Portable ZIP и откройте `START-AQUARIUM.bat`. Также можно открыть `index.html` напрямую.

Для PWA и Service Worker:

```bash
python -m http.server 8080
```

## ✅ Проверка

```bash
node --check bootstrap-v8.js
node --check v8-genetics.js
node tests/genetics-lab-test.js
node tests/v8-runtime-test.js
```
