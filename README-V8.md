# Living Aquarium V8 — Marine Genetics Lab

V8 добавляет генетическую лабораторию поверх V6 и V7. Прогресс хранится отдельно в `aquarium-v8-genetics`, а Deep Sea Expedition используется только как источник условий открытия линий и одноразового бонуса.

## Лаборатория

Пять локусов описывают окраску, плавники, размер, свечение и устойчивость. Есть шесть родительских линий, секвенирование, ДНК, реагенты, скрещивание, мутации, стабилизация и инкубатор до 12 эмбрионов.

Каталог содержит восемь фенотипов и пять достижений. Продвинутые линии открываются через XP, образцы V7 и уже исследованные фенотипы.

## Совместимость

V8 читает состояние Deep Sea Expedition, но не изменяет его. Собственный прогресс хранится только в `aquarium-v8-genetics`.

## Запуск и проверка

```bash
python -m http.server 8080
node --check bootstrap-v8.js
node --check v8-genetics.js
node tests/genetics-lab-test.js
node tests/v8-runtime-test.js
```

После запуска сервера откройте `http://localhost:8080/v8.html`.
