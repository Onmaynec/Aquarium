# Living Aquarium V8 — Marine Genetics Lab

V8 добавляет генетическую лабораторию поверх V6 Ocean Lab и V7 Deep Sea Expedition. Как и V7, новый модуль хранит своё состояние отдельно и не переписывает сохранения предыдущих слоёв.

## Хранилище

```text
aquarium-v8-genetics
```

V8 может читать состояние Deep Sea Expedition, чтобы открыть часть линий и один раз начислить бонус за собранные образцы. Запись обратно в V7 при этом не выполняется.

## Геном

Лаборатория работает с пятью локусами:

- окраска;
- плавники;
- размер;
- свечение;
- устойчивость.

Значения генов находятся в ограниченном диапазоне, а фенотип определяется сочетанием этих значений.

## Родительские линии

Доступны шесть линий:

| Линия | Как открывается |
| --- | --- |
| Коралловая | доступна сразу |
| Жемчужная | доступна сразу |
| Абиссальная | 3 типа образцов V7 или 160 XP |
| Термальная | посещены Термальные источники V7 или 300 XP |
| Лунная | 420 XP |
| Призматическая | 6 фенотипов в каталоге и 650 XP |

## Работа в лаборатории

Секвенирование расходует реагент и приносит ДНК и XP. Скрещивание двух выбранных линий создаёт эмбрион, наследующий значения генов обоих родителей.

При создании эмбриона возможна мутация одного локуса. Перед выращиванием геном можно стабилизировать за ДНК; это увеличивает исследовательскую ценность готового гибрида.

Инкубатор хранит до 12 эмбрионов.

## Фенотипы

Каталог включает восемь вариантов: биолюминесцентный, призматический, вуалехвостый, гигантский, иммунный страж, лунный жемчуг, термостойкий и дикий гибрид.

Отдельно отслеживаются пять достижений — от первого секвенирования до полного фенотипического атласа.

## Запуск из исходников

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/v8.html`.

## Сборка

```bash
python3 scripts/build-v8-release.py dist/v8-stage
```

Сборщик распаковывает базовый V6 runtime и подключает V7 и V8 как последовательные модули. В готовой сборке используется обычный `index.html`.

## Проверка

```bash
node --check bootstrap-v8.js
node --check v8-genetics.js
node tests/deep-sea-overlay-test.js
node tests/genetics-lab-test.js
node tests/v8-runtime-test.js
```
