## Главное в V10

### 🌐 Ocean Command Center

Откройте центр кнопкой **«Командный центр»** или клавишей `C`. V10 объединяет прогресс Deep Sea Expedition, Marine Genetics Lab и Reef Restoration Center в отдельный стратегический слой.

Командный центр не изменяет сохранения предыдущих версий. Его состояние хранится отдельно в ключе `aquarium-v10-command`.

### 🚢 Исследовательский флот

В распоряжении находятся три судна:

- **Nautilus**;
- **Calypso**;
- **Nereid**.

Каждое судно выполняет одну операцию в реальном времени. Одновременно можно вести до трёх миссий, а результат зависит от сложности региона, уровня специалистов и исследовательского ранга.

### 🗺️ Пять регионов

- Прибрежный контур;
- Коралловый пояс;
- Пелагический маршрут;
- Полярное течение;
- Абиссальная сеть.

Новые регионы открываются через глобальное влияние. Каждый регион даёт собственный бонус к снабжению, Ocean Index, влиянию, разведданным или XP.

### 📋 Совет операций

Доступны пять типов заданий:

- биосферная перепись;
- генетический резерв;
- коралловый мост;
- перехват загрязнения;
- абиссальный ретранслятор.

Операции требуют кредитов, разведданных и снабжения. Успешные миссии повышают глобальный индекс океана, влияние и командный уровень.

### 👥 Специалисты

Команду можно развивать до пятого уровня:

- навигатор снижает региональный риск;
- генетик усиливает генетические операции;
- эколог увеличивает прирост Ocean Index;
- инженер сокращает длительность миссий;
- аналитик повышает награды разведданными.

### 🔗 Интеграция V7–V9

V10 один раз рассчитывает безопасный бонус на основе:

- погружений и образцов V7;
- фенотипов и гибридов V8;
- репутации, высаженных колоний и здоровья секторов V9.

Предыдущие сохранения читаются только для расчёта бонуса и не изменяются.

### 🌍 Ocean Index

Глобальный индекс отражает устойчивость всей океанической сети. Он растёт от успешных операций и программ стабилизации и снижается при осложнениях. Для запуска глобальной программы требуются кредиты, разведданные и снабжение.

## Управление

| Клавиша | Действие |
|---|---|
| `C` | Ocean Command Center |
| `R` | Reef Restoration Center |
| `G` | Marine Genetics Lab |
| `X` | Deep Sea Expedition |
| `L` | Ocean Lab |
| `Space` | Пауза |
| `F` | Корм |
| `A` | Добавить рыбку |
| `E` | Редактор декораций |
| `P` | Фоторежим |
| `M` | Звук |
| `S` | Центр управления |
| `Esc` | Закрыть активный режим |

## Запуск

Откройте `v10.html` напрямую либо запустите локальный сервер:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080/v10.html`.

## Проверка

```bash
node --check bootstrap-v10.js
node --check v10-command.js
node --check service-worker-v10.js
node tests/command-center-test.js
node tests/v10-runtime-test.js
python3 scripts/build-v10-release.py dist/v10-stage
```
