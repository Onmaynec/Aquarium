# Living Aquarium V7 — Deep Sea Expedition

V7 — отдельный глубоководный overlay поверх V6 Ocean Lab. Он запускается через `v7.html`, подключает `v7-expedition.js` и хранит прогресс независимо в `aquarium-v7-deep-sea`.

Четыре района отличаются глубиной, расходом энергии и риском. Батискаф использует энергию, прочность корпуса и научные комплекты; сонар снижает вероятность аварии. В районах распределены 12 типов образцов, а модуль содержит XP, журнал и пять достижений.

V7 не меняет слоты V6. Для проверки используются `tests/deep-sea-overlay-test.js` и `tests/v7-runtime-test.js`.
