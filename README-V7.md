# Living Aquarium V7 — Deep Sea Expedition

V7 добавляет к стабильному V6 отдельную глубоководную систему. Модуль не меняет формат базовых сохранений и подключается поверх Ocean Lab через собственный entrypoint и storage key.

## Как устроена V7

В исходной ветке `v7.html` загружает базовый runtime V6 через `bootstrap-v7.js`, после чего подключается `v7-expedition.js`.

Экспедиционный прогресс хранится отдельно:

```text
aquarium-v7-deep-sea
```

Это позволяет запускать V6 и V7 рядом, не перезаписывая слоты основного аквариума.

## Районы

| Район | Глубина | Базовая энергия | Базовый риск |
| --- | ---: | ---: | ---: |
| Сумеречный риф | 600 м | 18% | 12% |
| Каньон сирен | 1200 м | 22% | 20% |
| Абиссальная равнина | 3500 м | 27% | 31% |
| Термальные источники | 2800 м | 25% | 27% |

Сумеречный риф доступен сразу. Каньон открывается после двух погружений; Абиссальная равнина — после пяти погружений или 300 XP; Термальные источники — после семи погружений или открытия семи типов образцов.

## Батискаф

У экспедиции три расходуемых ресурса: энергия, прочность корпуса и научные комплекты. Без комплекта начать погружение нельзя.

Сонар включается отдельно. Он немного увеличивает расход энергии, зато снижает вероятность аварии. При повреждении корпус теряет часть прочности; обслуживание восстанавливает корпус и энергию.

## Образцы и достижения

В четырёх районах распределены 12 типов находок — по три на зону. В коллекции учитывается количество каждого образца.

В V7 пять достижений:

- первое погружение;
- три погружения с сонаром;
- шесть открытых типов образцов;
- посещение Абиссальной равнины;
- посещение Термальных источников.

## Запуск

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/v7.html`.

В portable-релизе V7 собирается поверх распакованного V6 runtime и становится обычным `index.html`.

## Проверка

```bash
node --check v7-expedition.js
node --check bootstrap-v7.js
node tests/deep-sea-overlay-test.js
node tests/v7-runtime-test.js
```

`deep-sea-overlay-test.js` проверяет сам модуль, а `v7-runtime-test.js` — совместимость V7 с базовым runtime.
