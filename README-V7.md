# Living Aquarium V7 — Deep Sea Expedition

V7 — отдельный глубоководный overlay поверх V6 Ocean Lab. Он использует `v7-expedition.js` и хранит прогресс в `aquarium-v7-deep-sea`, не изменяя базовые слоты.

В модуле четыре района, батискаф с энергией/корпусом/комплектами, сонар, 12 типов образцов, XP, журнал и пять достижений. Новые зоны открываются по мере экспедиционного прогресса.

Исходная точка входа — `v7.html`; release-сборка подключает overlay к V6 и формирует обычный `index.html`.
