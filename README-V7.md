# Living Aquarium V7 — Deep Sea Expedition

V7 — отдельный глубоководный overlay поверх V6 Ocean Lab. Он запускается через `v7.html`, подключает `v7-expedition.js` и хранит прогресс независимо в `aquarium-v7-deep-sea`.

## Экспедиции

Четыре района отличаются глубиной, расходом энергии и риском: Сумеречный риф, Каньон сирен, Абиссальная равнина и Термальные источники. Батискаф использует энергию, прочность корпуса и научные комплекты; сонар снижает вероятность аварии.

В районах распределены 12 типов образцов. Новые зоны открываются через количество погружений, XP и коллекцию. Модуль содержит пять достижений и бортовой журнал.

## Совместимость

V7 не меняет слоты V6. Его данные хранятся отдельно и могут быть прочитаны более поздними overlay-модулями.

## Запуск и проверка

```bash
python -m http.server 8080
node --check v7-expedition.js
node tests/deep-sea-overlay-test.js
node tests/v7-runtime-test.js
```

После запуска сервера откройте `http://localhost:8080/v7.html`.
