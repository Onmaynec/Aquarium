# Living Aquarium V7 Deep Sea Expedition

V7 добавляет глубоководные экспедиции поверх V6, не меняя базовые сохранения. Модуль включает четыре района, батискаф с ресурсами, сонар, 12 типов образцов, XP, журнал и пять достижений.

Прогресс хранится в `aquarium-v7-deep-sea`. В release-сборке V7 подключается к распакованному V6 runtime и становится частью обычного `index.html`.
