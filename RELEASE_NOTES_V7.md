# Living Aquarium V7 Deep Sea Expedition

Исследуйте океан за пределами домашнего аквариума. V7 добавляет отдельный модуль экспедиций поверх стабильного симулятора V6.

## Основные возможности

- четыре глубоководных района, включая Абиссальную равнину и Термальные источники;
- батискаф с энергией, прочностью корпуса и научными комплектами;
- активный сонар для снижения риска;
- 12 научных образцов, XP Ocean Lab и бортовой журнал;
- пять достижений и постепенное открытие маршрутов;
- запуск панели клавишей `X`;
- сохранения V6 не изменяются.

## Файлы релиза

- `Aquarium-V7.0.0-Deep-Sea-Expedition-Portable.zip` — готовая версия для запуска;
- `Aquarium-V7.0.0-Deep-Sea-Expedition-Source.zip` — исходники V6 с V7 overlay;
- `Aquarium-V7.0.0-SHA256SUMS.txt` — контрольные суммы.
