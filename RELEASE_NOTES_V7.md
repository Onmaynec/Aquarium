# Living Aquarium V7 Deep Sea Expedition

V7 добавляет отдельный модуль глубоководных исследований поверх V6 Ocean Lab. Основной аквариум и его сохранения остаются независимыми от экспедиционного прогресса.

## Что входит в релиз

- четыре глубоководных района;
- батискаф с энергией, корпусом и научными комплектами;
- переключаемый сонар для снижения риска;
- 12 типов образцов;
- XP и бортовой журнал;
- пять достижений;
- отдельное сохранение `aquarium-v7-deep-sea`;
- клавиша `X` для открытия панели.

## Совместимость с V6

V7 использует проверенный V6 runtime как базу. Overlay подключается после основного `app.js` и не меняет слоты V6.

В исходной ветке V7 запускается через `v7.html`. В release workflow базовый runtime распаковывается, overlay добавляется к нему, после чего portable-архив получает обычный `index.html`.

## Файлы релиза

- `Aquarium-V7.0.0-Deep-Sea-Expedition-Portable.zip` — готовая автономная сборка;
- `Aquarium-V7.0.0-Deep-Sea-Expedition-Source.zip` — исходники и V7 tests;
- `Aquarium-V7.0.0-SHA256SUMS.txt` — SHA-256 контрольные суммы.
