# Living Aquarium V7 Deep Sea Expedition

V7 добавляет отдельный модуль глубоководных исследований поверх V6 Ocean Lab. Основной аквариум и его сохранения остаются независимыми от экспедиционного прогресса.

## Состав модуля

- четыре глубоководных района;
- батискаф с энергией, корпусом и научными комплектами;
- переключаемый сонар;
- 12 типов образцов;
- XP и бортовой журнал;
- пять достижений;
- отдельное сохранение `aquarium-v7-deep-sea`.

V7 подключается после базового приложения и не меняет слоты V6. В готовых release-сборках overlay объединяется с V6 runtime в один portable `index.html`.
