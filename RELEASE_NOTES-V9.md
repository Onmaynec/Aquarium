# Living Aquarium V9 Reef Restoration Center

V9 добавляет восстановление рифов поверх V6–V8: четыре сектора, питомник, четыре коралловые культуры, экологические проекты, климатические события и пять достижений.

Прогресс хранится в `aquarium-v9-restoration`. Данные V7/V8 используются только для одноразового legacy-бонуса. Release builder объединяет V6–V9 в portable `index.html`.
