# Changelog — Living Aquarium V8

## 8.0.0 — Marine Genetics Lab

### Added

- отдельный Genetics Lab overlay с клавишей `G`;
- пять генетических локусов и шесть родительских линий;
- секвенирование, ресурсы ДНК и реагенты;
- скрещивание, инкубатор до 12 эмбрионов, мутации и стабилизация генома;
- каталог из восьми фенотипов;
- пять достижений и лабораторный журнал;
- условия открытия продвинутых линий через XP и прогресс Deep Sea Expedition;
- одноразовый бонус ДНК/XP из образцов V7;
- отдельное сохранение `aquarium-v8-genetics`;
- точка входа `v8.html`, V8 manifest и Service Worker.

### Compatibility

- базовый V6 runtime не изменяется;
- V7 продолжает использовать собственное сохранение;
- V8 только читает прогресс V7 для условий/бонуса и не записывает его обратно;
- release builder объединяет V6, V7 и V8 в автономную сборку.
