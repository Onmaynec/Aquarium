# Living Aquarium V9 — Reef Restoration Center

V9 добавляет к Ocean Lab, Deep Sea Expedition и Marine Genetics Lab отдельную систему восстановления рифов. Новый модуль хранит прогресс самостоятельно и использует данные предыдущих версий только как источник одноразового стартового бонуса.

## Хранилище

```text
aquarium-v9-restoration
```

При чтении V7/V8 V9 не изменяет их данные.

## Сектора

| Сектор | Глубина | Стартовое здоровье | Загрязнение | Тепловой стресс | Репутация для открытия |
| --- | --- | ---: | ---: | ---: | ---: |
| Лагуна рассвета | 2–8 м | 42 | 46 | 18 | 0 |
| Коралловый сад | 8–18 м | 28 | 58 | 31 | 110 |
| Внешний шельф | 18–35 м | 20 | 68 | 38 | 270 |
| Голубая впадина | 35–70 м | 14 | 76 | 44 | 520 |

Репутация открывает следующие районы автоматически.

## Экологические проекты

**Обследование** стоит 45 кредитов, даёт XP и репутацию и находит 1–2 фрагмента. **Очистка** стоит 80 кредитов и требует хотя бы один дрон; она снижает загрязнение. **Охлаждение** стоит 95 кредитов и уменьшает тепловой стресс.

Высадка зависит от сектора: чем сложнее зона, тем больше колоний и кредитов требуется, но тем выше награда по репутации и XP.

После очистки, охлаждения или высадки может произойти климатическое событие — тепловая волна, загрязнение течением или полезная миграция фауны.

## Питомник

Одновременно можно выращивать до шести фрагментов. Каждая посадка расходует 2 фрагмента. После созревания культура даёт 2 колонии, иногда 3.

Доступны четыре культуры:

- ветвистая акропора;
- морской веер;
- мозговой коралл;
- ламинариевый купол.

Прогресс V7 и V8 может ускорять выращивание, но минимальное время ожидания ограничено.

## Наследие V7/V8

Одноразовый бонус учитывает количество погружений, типов глубоководных образцов, открытых фенотипов и гибридов. Он добавляет кредиты, фрагменты, репутацию и XP V9.

## Достижения

В V9 пять достижений: первая выращенная колония, восстановление лагуны, открытие всех секторов, 100 высаженных колоний и достижение устойчивого состояния во всех секторах.

## Запуск из исходников

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/v9.html`.

## Сборка и проверка

```bash
node --check bootstrap-v9.js
node --check v9-restoration.js
node --check service-worker-v9.js
node tests/restoration-center-test.js
node tests/v9-runtime-test.js
python3 scripts/build-v9-release.py dist/v9-stage
```

Готовая release-сборка объединяет V6, V7, V8 и V9 и использует обычный `index.html`.
