# Living Aquarium V9 — Reef Restoration Center

V9 добавляет систему восстановления рифов поверх V6–V8 и хранит прогресс в `aquarium-v9-restoration`.

Четыре сектора имеют здоровье, загрязнение и тепловой стресс. Репутация открывает новые зоны; доступны обследование, очистка, охлаждение и высадка колоний. Питомник рассчитан на шесть ячеек и четыре коралловые культуры.

V9 один раз читает прогресс V7/V8 для legacy-бонуса, но не изменяет старые сохранения. Исходная точка входа — `v9.html`; release builder объединяет V6–V9 в обычный `index.html`.
