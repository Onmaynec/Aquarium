# Living Aquarium V9 — Reef Restoration Center

V9 добавляет к Ocean Lab, Deep Sea Expedition и Marine Genetics Lab отдельную систему восстановления рифов. Новый модуль хранит прогресс самостоятельно и использует данные предыдущих версий только как источник одноразового стартового бонуса.

## Хранилище

```text
aquarium-v9-restoration
```

При чтении V7/V8 V9 не изменяет их данные.

## Сектора

| Сектор | Глубина | Стартовое здоровье | Загрязнение | Тепловой стресс | Репутация для открытия |
| --- | --- | ---: | ---: | ---: | ---: |
| Лагуна рассвета | 2–8 м | 42 | 46 | 18 | 0 |
| Коралловый сад | 8–18 м | 28 | 58 | 31 | 110 |
| Внешний шельф | 18–35 м | 20 | 68 | 38 | 270 |
| Голубая впадина | 35–70 м | 14 | 76 | 44 | 520 |

Репутация открывает новые районы автоматически.

## Экологические проекты

Обследование стоит 45 кредитов и находит 1–2 фрагмента. Очистка стоит 80 кредитов и требует хотя бы один дрон. Охлаждение стоит 95 кредитов. Высадка требует тем больше колоний и кредитов, чем сложнее сектор.

После экологических проектов может произойти климатическое событие: тепловая волна, приток загрязнения или полезная миграция фауны.

## Питомник

Питомник рассчитан на шесть ячеек. Каждая посадка расходует 2 фрагмента и после созревания даёт 2–3 колонии. Доступны ветвистая акропора, морской веер, мозговой коралл и ламинариевый купол.

## Наследие V7/V8

Одноразовый бонус учитывает погружения, открытые глубоководные образцы, фенотипы и гибриды. Он начисляет ресурсы V9, не переписывая сохранения предыдущих модулей.

## Запуск из исходников

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080/v9.html`. Корневой `index.html` в исходном репозитории остаётся точкой входа базовой V6.

## Сборка и проверка

```bash
node --check bootstrap-v9.js
node --check v9-restoration.js
node --check service-worker-v9.js
node tests/deep-sea-overlay-test.js
node tests/genetics-lab-test.js
node tests/restoration-center-test.js
node tests/v9-runtime-test.js
python3 scripts/build-v9-release.py dist/v9-stage
```

Готовая release-сборка объединяет V6–V9 и использует обычный `index.html`.
