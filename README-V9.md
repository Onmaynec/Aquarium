## Главное в V9

### Reef Restoration Center

Откройте центр кнопкой **«Восстановление»** или клавишей `R`. Управляйте четырьмя охраняемыми секторами, снижайте загрязнение и тепловой стресс, выращивайте кораллы и возвращайте устойчивые колонии в природу.

### Четыре сектора

- Лагуна рассвета;
- Коралловый сад;
- Внешний шельф;
- Голубая впадина.

Новые сектора открываются с ростом экологической репутации.

### Коралловый питомник

Доступны четыре культуры: ветвистая акропора, морской веер, мозговой коралл и ламинариевый купол. Фрагменты созревают в питомнике, после чего колонии можно высаживать в выбранные зоны.

### Экологические программы

- разведка сектора;
- очистка дронами;
- охлаждение и тепловые щиты;
- высадка восстановленных колоний;
- случайные климатические события;
- пять достижений и журнал проектов.

### Связь с V7 и V8

V9 один раз рассчитывает безопасный бонус по научным образцам Deep Sea Expedition и результатам Marine Genetics Lab. Сохранения предыдущих версий не изменяются.

## Управление

| Клавиша | Действие |
|---|---|
| `R` | Reef Restoration Center |
| `G` | Marine Genetics Lab |
| `X` | Deep Sea Expedition |
| `L` | Ocean Lab |
| `Space` | Пауза |
| `F` | Корм |
| `A` | Добавить рыбку |
| `E` | Редактор декораций |
| `P` | Фоторежим |
| `M` | Звук |
| `S` | Центр управления |
| `Esc` | Закрыть активный режим |

## Запуск

Распакуйте Portable ZIP и откройте `START-AQUARIUM.bat` либо `index.html`.

Для PWA:

```bash
python -m http.server 8080
```
