# Living Aquarium V9 — Reef Restoration Center

V9 добавляет к Living Aquarium отдельный центр восстановления рифов. Это не замена базового аквариума: Reef Restoration Center подключается поверх механик V6, Deep Sea Expedition из V7 и Marine Genetics Lab из V8.

Версия V9 хранит свой прогресс отдельно и не изменяет сохранения предыдущих дополнений.

## Что появилось в V9

Главная новая система — Reef Restoration Center, который открывается клавишей `R` или кнопкой «Восстановление» в интерфейсе.

В центре доступны четыре охраняемых сектора:

| Сектор | Глубина | Когда доступен |
| --- | --- | --- |
| Лагуна рассвета | 2–8 м | сразу |
| Коралловый сад | 8–18 м | после роста репутации |
| Внешний шельф | 18–35 м | после роста репутации |
| Голубая впадина | 35–70 м | после роста репутации |

Для каждого сектора отслеживаются здоровье, загрязнение и тепловой стресс. Игрок может проводить обследования, отправлять дроны на очистку, разворачивать охлаждение и высаживать выращенные колонии.

## Коралловый питомник

Питомник рассчитан максимум на шесть одновременно выращиваемых фрагментов. В V9 есть четыре культуры:

- ветвистая акропора;
- морской веер;
- мозговой коралл;
- ламинариевый купол.

Выращенные фрагменты превращаются в колонии, которые затем используются для восстановления открытых секторов.

## Прогресс и события

В центре используются отдельные ресурсы: кредиты, коралловые фрагменты, готовые колонии, дроны, экологическая репутация и исследовательский XP.

Во время проектов могут происходить климатические события: тепловая волна, приток загрязнения или благоприятная миграция фауны. В системе также есть пять достижений и журнал последних действий.

## Совместимость с V7 и V8

Сохранение V9 находится в ключе:

```text
aquarium-v9-restoration
```

При первом запуске V9 читает прогресс `aquarium-v7-deep-sea` и `aquarium-v8-genetics`, чтобы рассчитать одноразовый стартовый бонус. Данные старых версий используются только для чтения и не перезаписываются.

## Запуск

Если используется готовый V9 portable-архив, откройте `index.html` или `START-AQUARIUM.bat`.

Если запускается именно исходный репозиторий, используйте V9-точку входа:

```bash
python -m http.server 8080
```

После запуска сервера откройте:

```text
http://localhost:8080/v9.html
```

Корневой `index.html` в исходном репозитории относится к базовой V6.

## Сборка portable-версии

```bash
python3 scripts/build-v9-release.py dist/v9-stage
```

Сборщик извлекает базовый runtime, добавляет `v7-expedition.js`, `v8-genetics.js` и `v9-restoration.js`, подставляет V9 manifest и Service Worker и формирует готовую структуру, где точкой входа уже является `index.html`.
