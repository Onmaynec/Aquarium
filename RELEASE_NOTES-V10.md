# Living Aquarium V10 Ocean Command Center

V10 превращает набор научных overlay-модулей Aquarium в отдельный стратегический слой управления океанической сетью.

## Состав релиза

- три исследовательских судна;
- пять регионов с разным риском;
- пять операций реального времени;
- пять специалистов с прокачкой до 5 уровня;
- Ocean Index, влияние, XP, разведданные и снабжение;
- стабилизационная программа;
- шесть достижений;
- одноразовая интеграция прогресса V7–V9;
- отдельное сохранение `aquarium-v10-command`.

## Совместимость

V10 не переписывает V6–V9. При первом использовании данные предыдущих модулей читаются только для расчёта стартового legacy-бонуса.

Release builder объединяет V6 runtime и overlays V7–V10 в автономный `index.html` с PWA/offline-конфигурацией.

## Артефакты

Релиз публикует Portable ZIP без тестовой инфраструктуры, Source ZIP с тестами и builder-скриптами и SHA-256 контрольные суммы обоих архивов.
